The SKUs the course's arithmetic runs on. Every figure that states a floor names its SKU; vendor figures come with the document, never the rumor.

1The reference SKU

Single-GPU arithmetic in this course runs on one H200 SXM: 141 GB HBM3e at 4.8 TB/s, 989.5 TFLOPS dense bf16. It is the same reference as the sibling courses, so floors compare across all three.

2What the roster needs

Resident weights in bf16 run from about 15 GB (Qwen2.5-7B) to about 1.3 TB (DeepSeek-V3). The state chapters (6, 8, 9, 20, 23) work out, per model, what a full context weighs beside those weights, and which combinations fit the 141 GB reference card. The rule is always the same: weights plus state plus runtime buffers, with every assumption named.

3Beyond one GPU

Multi-GPU serving (expert parallelism, disaggregation, NVLink domains) belongs to the sibling courses: Two Engines for one model across GPUs, Two Orchestrators for fleets. Chapter 29 points at the exact chapters.
