EveryModel

How every important model architecture since ChatGPT works, from the LLaMA recipe through GQA, MoE, MLA, hybrids, sparse attention and diffusion. Each chapter runs the same workload through an incumbent and a challenger, step by step, and pins every claim to the source.

Fifteen open-weight configs carry the course, from Mistral-7B (2023) to Kimi-K3, GLM-5.3 and DeepSeek-V4.1-Flash (2026). Gated flagships appear as cited deltas until their configs are publicly fetchable. New to transformers? Read Start here first. Otherwise start with the timeline or chapter 1.

Every chapter works the same way

Watch two designs run, then build a small version of the mechanism yourself, then read the configs and code behind it. You need Python and ten minutes of foundations — tokens, matrix multiplication, attention, normalization and residuals. If those aren't old friends, read Start here first; chapter 1 assumes them from its first figure.

See it

A step-through figure runs one workload through the incumbent design on channel A and the challenger on channel B, on a single shared clock. A marked step shows where the two designs compute something different, and why.

Build it

Short Python labs run in your browser or locally with pytest. They use a tiny transformer and fixture configs from the pinned revisions, so the tests check real shapes: head counts, cache bytes, active experts.

Read it

Every config key, class and line number links to the revision this course is pinned to. The build checks each reference against that exact commit, so the links stay correct as the projects move on.

The course

Six parts, from the decoder block everyone inherited to diffusion. Each chapter ends on a question, and the next chapter answers it. By the end, every architecture should look like the obvious answer to a problem you've already met.

Pinned to source

Line numbers that stay correct

Guides to model architectures go stale in months. A config key is renamed, a default changes, and the guide is wrong without anyone noticing. This course is pinned to one release of Transformers and one revision of each roster config. The build reads them at those pins and refuses to publish a reference that no longer points at what the text says it does.

A drift check runs every week, and a new edition ships every eight weeks: newly released architectures arrive as cited deltas first and join the pinned roster when their configs are publicly fetchable. How this course is checked
