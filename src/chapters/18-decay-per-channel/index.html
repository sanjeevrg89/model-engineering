Gated DeltaNet forgets with one scalar per head. Kimi Delta Attention forgets per channel: every feature dimension gets its own decay rate, learned beside the update. Kimi-K3 runs that mechanism across 69 linear layers with NoPE MLA layers every fourth position. This chapter updates one memory row twice: scalar gating on channel A, channel-wise decay on channel B.

The 2-minute version

One gate per head becomes one decay per feature channel: finer forgetting over the same fixed-size memory. Kimi-K3 pairs 69 KDA layers with NoPE MLA every fourth layer — position rides the recurrence, retrieval re-anchors periodically.

18.1One gate per head, one gate per channel

The difference is resolution. A scalar gate keeps or drops a head's whole memory row at once; a channel-wise gate keeps the syntax channels and drops the stale topic channels, or the reverse next token. The Kimi Linear paper, which introduces KDA as a refinement of Gated DeltaNet, reports the 3:1 KDA-to-MLA hybrid beating full attention at matched scale across short-context, long-context and RL post-training — cited here as the paper's claim (arXiv:2510.26692), with the config below as the shipped evidence.

18.3Every fourth layer looks back

The full-attention list runs 4, 8, 12, … 92, 93 : 24 NoPE MLA layers spaced through 69 KDA layers, a uniform 3:1 ratio the paper's ablations select over 1:1 (same quality, more cost) and 7:1 (worse validation). The recurrent layers compress history into fixed state; every fourth layer re-anchors retrieval to individual cached tokens. KV growth concentrates in those 24 layers — 27,648 latent bytes per token in bf16 from chapter 8's lab — while the other 69 hold constant memory at any context length.

18.5Check yourself

What does KDA's channel-wise gate control that GDN's scalar gate doesn't?

  1. Which experts activate per token
  2. The forgetting rate of each feature dimension independently
  3. The attention window size per layer
  4. The learning rate per layer
A scalar keeps or drops a head's whole row; a diagonal gate retains syntax channels while dropping stale ones. Finer control over the same fixed-size memory.

Why can Kimi-K3's MLA layers use NoPE?

  1. 1M contexts don't need positions
  2. MXFP4 quantization encodes position
  3. The KDA layers carry position as the dedicated position-aware operator
  4. RoPE theta is set to zero
Position is a job, not a layer (chapter 10). KDA's recency-aware gating takes the job, and MLA converts cleanly to MQA at inference as a bonus.

How many of Kimi-K3's 93 layers are full MLA, and how are they placed?

  1. 24, every fourth layer plus the last
  2. 69, everywhere except the last 24
  3. 31, every third layer
  4. 93 — every layer is full attention
The full_attn_layers list runs 4, 8, …, 92, 93: uniform 3:1 interleaving so retrieval re-anchors regularly through the recurrent stack.

Takeaways
  • Channel-wise decay refines scalar gating: independent forgetting per feature dimension.
  • NoPE MLA works because KDA carries position; the payoff is MQA conversion and theta-free training.
  • 24 full layers in 93, every fourth: retrieval re-anchors through fixed-state recurrence.
  • Paper claims stay attributed; the config is the shipped corroboration.
