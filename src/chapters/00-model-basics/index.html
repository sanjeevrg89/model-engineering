Kimi-K3 stacks one block 93 times, DeepSeek-V4.1-Flash 76 times, Mistral-7B just 32. Everything this course does — the attention zoo, the expert routers, the caches — is machinery bolted onto or inside that block. So the floor comes first: five ideas, one square-root symbol, and every number taken from the two configs the whole course starts with.

This chapter runs one token through an entire model twice, not through one block: once on Qwen2.5-7B's dimensions, once on Mistral-7B's. Chapter 1 then zooms into the block itself and walks the same token through it step by step.

The 2-minute version

A model has never read a word. Text becomes tokens; each token id picks a vector of 3,584 or 4,096 numbers from a table; the model rewrites that vector stack by stack with nothing fancier than multiply-and-add between learned matrices; attention is the lookup that lets each position pull context from earlier ones; RMSNorm keeps every vector at comparable size; the residual add means blocks only ever learn a small edit. At the end, a table maps the final vector to 152,064 or 32,000 logits — one score per possible next token.

After this chapter you can: define token, vector, weights, head, logits in one line each · compute the width of any projection from a config · explain what attention chooses and what a residual protects.

0.1One token's lifetime through the whole model

The figure follows a single token from text to its effect on the next token, across the whole network. Nothing here requires more than one number concept: a vector is a list of numbers, a weights matrix is a grid of numbers, and every stage multiplies, adds, or picks.

The vocabulary lengths differ by five to one: 152,064 possible next tokens in Qwen2.5-7B against 32,000 in Mistral-7B . That asymmetry runs through the rest of the course: chapter 2 breaks vocabulary mechanics down, chapter 5 prices the final scoring table, chapter 21 relies on it for multiple tokens per pass.

0.2Words in, numbers out

A model has never seen a word. It sees tokens: the fragments a tokenizer cuts text into — a common word whole, a rare word in pieces, punctuation alone — and each fragment stores as one integer id. The id's job is to pick a row from the model's first table. That row is a list of hidden_size numbers — 3,584 in Qwen2.5-7B , 4,096 in Mistral-7B — and it is the token's vector: the only representation the model ever works with.

0.3The only arithmetic that matters

Everything a block computes reduces to one operation. Take the token's vector — n numbers — and a learned matrix of n rows by m columns, the weights. One output number = one row of the matrix times the whole vector: multiply each pair, add the products. Do that for all m rows and you have m new numbers; that output is a projection. The widths tell you the cost: a projection from 3,584 numbers out to 18,944 owns 3,584 × 18,944 weights, and the feed-forward that owns it is the single biggest ingredient of a block. Chapter 1 measures it; chapter 22 stores it more cheaply.

0.4Attention is a lookup

Each token's vector needs context from earlier tokens, and attention gathers it in three steps. Every position projects its vector into a query (what am I looking for), while earlier positions project into keys (what each offers) and values (what each hands over when chosen). Matching each query against every key gives scores; the scores squeeze to positive weights that sum to one; then attention returns the weighted blend of the values.

The lookup runs in parallel copies called heads — 28 of them in Qwen2.5-7B , each with its own query, key and value matrices, so one head can track syntax while another tracks who "it" refers to. Heads are the machine's eyes; how many get cached, shared or compressed is chapters 1, 6, 8 and 9.

0.5Normalization

Twenty-eight blocks in a row would drift: vectors could grow, shrink or lean. RMSNorm fixes volume. It divides the incoming vector by its root mean square — the square root of the average of the squared entries — and then scales each entry by a learned gain. The epsilon, 1e-06 in Qwen2.5-7B , only keeps the division from dividing by zero. After the norm, every block begins with the token at a comparable size, whatever its adventure so far.

0.6The residual: blocks edit, never replace

Each sub-block computes its projection output and then adds the original input back in: output = input + change. That is the residual, and its job is depth. The unchanged input always has a clean path around every projection, so the model only ever has to learn the small correction it wants applied, and a 93-layer stack stays trainable where a 93-layer chain of replacements would not.

0.8Check yourself

A model reads a short prompt. After tokenization and embedding, what exists for one fragment?

  1. One integer id, which has picked one vector of hidden_size numbers
  2. One word meaning, stored as text
  3. One number per letter of the word
  4. The whole vocabulary table
The id is an index; the embedding table turns it into one vector — 3,584 numbers in Qwen2.5-7B, 4,096 in Mistral-7B (§0.2).

A projection goes from 3,584 numbers out to 18,944. How many weights does it own?

  1. 3,584 + 18,944
  2. 3,584 × 18,944
  3. 18,944 / 3,584
  4. None — projections share the embedding's weights
Every output number needs one weight per input number: rows times columns (§0.3). That product is why the feed-forward dominates a block.

What does the score between a query and a key decide?

  1. Which expert routes the token
  2. The next token id
  3. How much of that position's value blends into the attention output
  4. The vector's size after the block
Scores squeeze into weights that sum to one; attention returns the weighted blend of the values (§0.4). Choosing is attention's only job.

What makes a 93-layer stack trainable where a chain of replacements would not be?

  1. RMSNorm, because it keeps sizes comparable
  2. The residual add: blocks learn a change to the input, and the input always keeps a clean path through
  3. The small 32,000-token vocabulary
  4. Grouped-query attention
Output = input + change means the model only learns corrections (§0.6). Norm is the other guardrail, but the clean path is the residual's doing.
Takeaways
  • Tokens are ids; ids are rows of numbers — 152,064 vocabulary entries exist to become one 3,584-number vector per token .
  • Every mechanism is multiply-and-add plus a decision: attention, the feed-forward and the final scorer are all projections.
  • Attention chooses; the other stages compute. Query-key scores decide which earlier positions donate values, and heads are parallel choices at work.
  • Norm and residual are depth's guardrails: one keeps every vector comparable in size, the other guarantees blocks only learn small edits on a clean path.
